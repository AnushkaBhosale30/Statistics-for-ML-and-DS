# 📊 SMLDS — Statistical Analysis & Experiments

### 🧠 Exploring Data • Discovering Patterns • Applying Statistics

Welcome to my **Statistical Analysis & Experiments** repository! 🚀

This project contains **5 hands-on statistical experiments** performed using **Python** and the **Pima Indians Diabetes Dataset**. Each experiment explores a different statistical technique and includes the **source code, output, and documentation**.

---

## 🧪 What's Inside?

| 🔢     | Experiment                                | 🔍 Focus                                    |
| ------ | ----------------------------------------- | ------------------------------------------- |
| **01** | 🔎 Exploratory Statistical Analysis       | Dataset structure, data quality & patterns  |
| **02** | 🧪 Estimation & Hypothesis Testing        | Population estimation & statistical testing |
| **03** | 🔗 Correlation & Distance Measures        | Relationships, distances & preprocessing    |
| **04** | 📊 Descriptive Statistics & Visualization | Summaries, distributions & visual analysis  |
| **05** | 🔄 Bootstrap & Permutation Resampling     | Confidence intervals & group differences    |
